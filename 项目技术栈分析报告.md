### **1. 缓存设计模式**

#### 缓存穿透解决方案
**问题**: 恶意查询不存在的数据，绕过缓存直击数据库

**解决方案 - 缓存空值**:
```java
public Doctor queryById(Long id) {
    String key = CACHE_DOCTOR_KEY + id;
    // 1. 查询Redis
    String json = stringRedisTemplate.opsForValue().get(key);
    if (StrUtil.isNotBlank(json)) {
        return JSONUtil.toBean(json, Doctor.class);
    }
    
    // 2. 判断是否为空值
    if (json != null) {
        return null; // 缓存的空值
    }
    
    // 3. 查询数据库
    Doctor doctor = getById(id);
    
    // 4. 缓存结果（包括null）
    if (doctor == null) {
        stringRedisTemplate.opsForValue().set(key, "", 2, TimeUnit.MINUTES);
        return null;
    }
    
    stringRedisTemplate.opsForValue().set(key, JSONUtil.toJsonStr(doctor), 30, TimeUnit.MINUTES);
    return doctor;
}
```

#### 缓存击穿解决方案
**问题**: 热点数据过期瞬间，大量请求击穿缓存

**方案1 - 互斥锁（Mutex）**:
```java
public Doctor queryWithMutex(Long id) {
    String key = CACHE_DOCTOR_KEY + id;
    String json = stringRedisTemplate.opsForValue().get(key);
    if (StrUtil.isNotBlank(json)) {
        return JSONUtil.toBean(json, Doctor.class);
    }
    
    // 获取互斥锁
    String lockKey = LOCK_DOCTOR_KEY + id;
    try {
        boolean isLock = tryLock(lockKey);
        if (!isLock) {
            // 未获取锁，休眠重试
            Thread.sleep(50);
            return queryWithMutex(id);
        }
        
        // 获取锁成功，查询数据库
        Doctor doctor = getById(id);
        stringRedisTemplate.opsForValue().set(key, JSONUtil.toJsonStr(doctor), 30, TimeUnit.MINUTES);
        return doctor;
    } finally {
        unlock(lockKey);
    }
}

private boolean tryLock(String key) {
    Boolean flag = stringRedisTemplate.opsForValue()
        .setIfAbsent(key, "1", 10, TimeUnit.SECONDS);
    return BooleanUtil.isTrue(flag);
}
```

**方案2 - 逻辑过期（无锁）**:
```java
@Data
class RedisData {
    private LocalDateTime expireTime; // 逻辑过期时间
    private Object data;
}

public Doctor queryWithLogicalExpire(Long id) {
    String key = CACHE_DOCTOR_KEY + id;
    String json = stringRedisTemplate.opsForValue().get(key);
    
    if (StrUtil.isBlank(json)) {
        return null; // 缓存未命中
    }
    
    RedisData redisData = JSONUtil.toBean(json, RedisData.class);
    Doctor doctor = JSONUtil.toBean((JSONObject) redisData.getData(), Doctor.class);
    LocalDateTime expireTime = redisData.getExpireTime();
    
    // 判断是否过期
    if (expireTime.isAfter(LocalDateTime.now())) {
        return doctor; // 未过期
    }
    
    // 已过期，尝试获取锁
    String lockKey = LOCK_DOCTOR_KEY + id;
    boolean isLock = tryLock(lockKey);
    if (isLock) {
        // 开启独立线程重建缓存
        CACHE_REBUILD_EXECUTOR.submit(() -> {
            try {
                saveDoctor2Redis(id, 30L);
            } finally {
                unlock(lockKey);
            }
        });
    }
    
    // 返回过期数据
    return doctor;
}
```

**对比**:
| 方案 | 优点 | 缺点 | 适用场景 |
|-----|------|------|---------|
| 互斥锁 | 强一致性，实现简单 | 性能较差，可能死锁 | 一致性要求高 |
| 逻辑过期 | 高可用，性能好 | 弱一致性，额外内存 | 高并发热点数据 |

#### 缓存雪崩解决方案
**问题**: 大量缓存同时失效，数据库瞬间压力剧增

**解决方案**:


#### 缓存更新策略
**策略选择**: Cache-Aside Pattern（旁路缓存）

**操作顺序**: **先更新数据库，再删除缓存**

```java
@Transactional
public Result updateDoctor(Doctor doctor) {
    Long id = doctor.getId();
    if (id == null) {
        return Result.fail("医生ID不能为空");
    }
    
    // 1. 更新数据库
    updateById(doctor);
    
    // 2. 删除缓存
    stringRedisTemplate.delete(CACHE_DOCTOR_KEY + id);
    
    return Result.ok();
}
```

**为什么不是"先删缓存，再更新数据库"？**
```
线程1: 删除缓存
线程2: 查询缓存（未命中） → 查数据库（旧数据） → 写入缓存（旧数据）
线程1: 更新数据库（新数据）
结果: 缓存是旧数据，数据库是新数据 ❌
```

**为什么不是"先更新数据库，再更新缓存"？**
```
1. 每次写操作都要更新缓存，浪费资源
2. 并发写时，缓存数据顺序不可控
3. 复杂计算的缓存更新成本高
```

#### Lua脚本保证原子性
**seckill.lua**:
```lua
-- 参数列表
local voucherId = ARGV[1]  -- 预约券ID
local userId = ARGV[2]     -- 用户ID

-- 数据KEY
local stockKey = 'seckill:stock:' .. voucherId       -- 库存KEY
local orderKey = 'seckill:order:' .. voucherId       -- 订单KEY

-- 1. 判断库存是否充足

    return 1  -- 库存不足
end

-- 2. 判断用户是否已下单

end

-- 3. 扣减库存
redis.call('incrby', stockKey, -1)
```

#### 全局唯一ID生成器
**需求**:
- 唯一性
- 高可用
- 高性能
- 递增性
- 安全性（不暴露信息）

**设计** - 时间戳 + 自增序列:
```java
public class RedisIdWorker {
    private static final long BEGIN_TIMESTAMP = 1640995200L; // 2022-01-01 00:00:00
    private static final int COUNT_BITS = 32;
    
    private StringRedisTemplate stringRedisTemplate;
    
    public long nextId(String keyPrefix) {
        // 1. 生成时间戳（秒级）
        LocalDateTime now = LocalDateTime.now();
        long nowSecond = now.toEpochSecond(ZoneOffset.UTC);
        long timestamp = nowSecond - BEGIN_TIMESTAMP;
        
        // 2. 生成序列号
        String date = now.format(DateTimeFormatter.ofPattern("yyyy:MM:dd"));
        long count = stringRedisTemplate.opsForValue().increment("icr:" + keyPrefix + ":" + date);
        
        // 3. 拼接返回（位运算）
        return timestamp << COUNT_BITS | count;
    }
}
```

**ID结构**:
```
|----1bit----|------31bit------|--------32bit--------|
   符号位       时间戳(秒)         自增序列号
     0         1234567890          000000001
```

**优势**:
- ✅ 全局唯一（时间戳 + Redis原子自增）
- ✅ 高性能（Redis单线程+内存操作）
- ✅ 趋势递增（利于数据库索引）
- ✅ 安全性（不暴露业务信息）
- ✅ 容灾（按天分Key，便于统计）

#### 实现代码
**存储医生坐标**:
```java
@Override
public Result saveDoctorGeo() {
    // 1. 查询所有医生
    List<Doctor> list = list();
    
    // 2. 按科室分组
    Map<Long, List<Doctor>> map = list.stream()
        .collect(Collectors.groupingBy(Doctor::getDepartmentId));
    
    // 3. 分批写入Redis
    for (Map.Entry<Long, List<Doctor>> entry : map.entrySet()) {
        Long departmentId = entry.getKey();
        String key = DOCTOR_GEO_KEY + departmentId;
        List<Doctor> doctors = entry.getValue();
        
        // 批量添加
        List<RedisGeoCommands.GeoLocation<String>> locations = new ArrayList<>();
        for (Doctor doctor : doctors) {
            locations.add(new RedisGeoCommands.GeoLocation<>(
                doctor.getId().toString(),
                new Point(doctor.getX(), doctor.getY())
            ));
        }
        
        stringRedisTemplate.opsForGeo().add(key, locations);
    }
    
    return Result.ok();
}
```

```java
        // 不需要坐标查询，按数据库查询
        Page<Doctor> page = query()
            .eq("department_id", departmentId)
            .page(new Page<>(current, SystemConstants.DEFAULT_PAGE_SIZE));
        return Result.ok(page.getRecords());
    }
    
    // 2. 计算分页参数
    int from = (current - 1) * SystemConstants.DEFAULT_PAGE_SIZE;
    int end = current * SystemConstants.DEFAULT_PAGE_SIZE;
    
    // 3. 查询Redis，按距离排序
    String key = DOCTOR_GEO_KEY + departmentId;
    GeoResults<RedisGeoCommands.GeoLocation<String>> results = stringRedisTemplate.opsForGeo()
        .search(
            key,
            GeoReference.fromCoordinate(x, y),
            new Distance(5000),  // 5公里
            RedisGeoCommands.GeoSearchCommandArgs.newGeoSearchArgs()
                .includeDistance()
                .limit(end)
        );
    
    // 4. 解析ID
    if (results == null) {
        return Result.ok(Collections.emptyList());
    }
    
    List<GeoResult<RedisGeoCommands.GeoLocation<String>>> list = results.getContent();
    if (list.size() <= from) {
        return Result.ok(Collections.emptyList());
    }
    
    // 5. 截取from ~ end
    List<Long> ids = new ArrayList<>(list.size());
    Map<String, Distance> distanceMap = new HashMap<>(list.size());
    
    list.stream().skip(from).forEach(result -> {
        String doctorIdStr = result.getContent().getName();
        ids.add(Long.valueOf(doctorIdStr));
        Distance distance = result.getDistance();
        distanceMap.put(doctorIdStr, distance);
    });
    
    // 6. 根据ID查询医生
    String idStr = StrUtil.join(",", ids);
    List<Doctor> doctors = query().in("id", ids).last("ORDER BY FIELD(id," + idStr + ")").list();
    
    for (Doctor doctor : doctors) {
        doctor.setDistance(distanceMap.get(doctor.getId().toString()).getValue());
    }
    
    return Result.ok(doctors);
}
```

```java
        if (isSuccess) {

        boolean isSuccess = update().setSql("liked = liked - 1").eq("id", id).update();
        if (isSuccess) {
            // 从ZSet集合移除
            stringRedisTemplate.opsForZSet().remove(key, userId.toString());
        }
    }
    
    return Result.ok();
}
```

### **5. 用户签到统计**

#### Bitmap实现签到日历
**原理**: 一个月最多31天，用31个bit位表示每天的签到状态

**数据结构**:
```bash
Key: sign:{userId}:{yyyyMM}
Value: Bitmap (31 bits)

示例: sign:1:202610
Bit位:  0  1  2  3  4  5  ... 30
含义: 1号 2号 3号 4号 5号 6号 ... 31号
```

**签到**:
```java
@Override
public Result sign() {
    // 1. 获取当前登录用户
    Long userId = UserHolder.getUser().getId();
    
    // 2. 获取日期
    LocalDateTime now = LocalDateTime.now();
    String keySuffix = now.format(DateTimeFormatter.ofPattern(":yyyyMM"));
    String key = USER_SIGN_KEY + userId + keySuffix;
    
    // 3. 获取今天是本月的第几天
    int dayOfMonth = now.getDayOfMonth();
    
    // 4. 写入Redis SETBIT key offset 1
    stringRedisTemplate.opsForValue().setBit(key, dayOfMonth - 1, true);
    
    return Result.ok();
}
```

**统计连续签到天数**:
```java
@Override
public Result signCount() {
    // 1. 获取当前登录用户
    Long userId = UserHolder.getUser().getId();
    
    // 2. 获取日期
    LocalDateTime now = LocalDateTime.now();
    String keySuffix = now.format(DateTimeFormatter.ofPattern(":yyyyMM"));
    String key = USER_SIGN_KEY + userId + keySuffix;
    
    // 3. 获取今天是本月的第几天
    int dayOfMonth = now.getDayOfMonth();
    
    // 4. 获取本月截止今天为止的所有签到记录，返回的是一个十进制数字 BITFIELD key GET u{dayOfMonth} 0
    List<Long> result = stringRedisTemplate.opsForValue().bitField(
        key,
        BitFieldSubCommands.create()
            .get(BitFieldSubCommands.BitFieldType.unsigned(dayOfMonth))
            .valueAt(0)
    );
    
    if (result == null || result.isEmpty()) {
        return Result.ok(0);
    }
    
    Long num = result.get(0);
    if (num == null || num == 0) {
        return Result.ok(0);
    }
    
    // 5. 循环遍历，从右往左，检查每一位
    int count = 0;
    while (true) {
        // 让这个数字与1做与运算，得到最后一位
        if ((num & 1) == 0) {
            // 如果为0，说明未签到，结束
            break;
        } else {
            // 如果不为0，说明已签到，计数器+1
            count++;
        }
        
        // 数字右移一位
        num >>>= 1;
    }
    
    return Result.ok(count);
}
```

**Bitmap命令**:
```bash
# 签到
SETBIT sign:1:202610 2 1  # 10月3日签到

# 获取某天签到状态
GETBIT sign:1:202610 2

# 统计签到天数
BITCOUNT sign:1:202610

# 获取连续签到（BitField）
BITFIELD sign:1:202610 GET u3 0  # 获取前3天的签到状态
```

**优势**:
- ✅ 极致节省内存（1个月只需4字节）
- ✅ 高性能（位操作）
- ✅ 原子性（单命令操作）

## 🔐 安全与认证

### **拦截器链设计**

**执行顺序**: RefreshTokenInterceptor (order=0) → LoginInterceptor (order=1)

#### 1. RefreshTokenInterceptor - Token刷新
```java
public class RefreshTokenInterceptor implements HandlerInterceptor {
    
    private StringRedisTemplate stringRedisTemplate;
    
    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) {
        // 1. 获取请求头中的token
        String token = request.getHeader("authorization");
        if (StrUtil.isBlank(token)) {
            return true; // 放行，让LoginInterceptor处理
        }
        
        // 2. 基于token获取Redis中的用户
        String key = LOGIN_USER_KEY + token;
        Map<Object, Object> userMap = stringRedisTemplate.opsForHash().entries(key);
        
        // 3. 判断用户是否存在
        if (userMap.isEmpty()) {
            return true;
        }
        
        // 4. 将查询到的Hash数据转为UserDTO对象
        UserDTO userDTO = BeanUtil.fillBeanWithMap(userMap, new UserDTO(), false);
        
        // 5. 存在，保存用户信息到ThreadLocal
        UserHolder.saveUser(userDTO);
        
        // 6. 刷新token有效期
        stringRedisTemplate.expire(key, LOGIN_USER_TTL, TimeUnit.MINUTES);
        
        // 7. 放行
        return true;
    }
    
    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler, Exception ex) {
        // 移除用户
        UserHolder.removeUser();
    }
}
```

#### 2. LoginInterceptor - 登录校验
```java
public class LoginInterceptor implements HandlerInterceptor {
    
    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) {
        // 1. 判断是否需要拦截（ThreadLocal中是否有用户）
        if (UserHolder.getUser() == null) {
            // 没有，需要拦截，设置状态码
            response.setStatus(401);
            return false;
        }
        
        // 有用户，放行
        return true;
    }
}
```

#### 配置拦截器
```java
@Configuration
public class MvcConfig implements WebMvcConfigurer {
    
    @Resource
    private StringRedisTemplate stringRedisTemplate;
    
    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        // Token刷新拦截器（拦截所有请求）
        registry.addInterceptor(new RefreshTokenInterceptor(stringRedisTemplate))
            .addPathPatterns("/**")
            .order(0);
        
        // 登录拦截器（排除部分路径）
        registry.addInterceptor(new LoginInterceptor())
            .excludePathPatterns(
                "/department/**",    // 科室查询
                "/doctor/**",        // 医生查询
                "/schedule/**",      // 排班查询
                "/upload/**",        // 文件上传
                "/review/hot",       // 热门评价
                "/user/code",        // 发送验证码
                "/user/login"        // 用户登录
            )
            .order(1);
    }
}
```

**设计思路**:
1. **第一层**（RefreshTokenInterceptor）：负责解析Token，刷新过期时间，保存用户到ThreadLocal
2. **第二层**（LoginInterceptor）：检查ThreadLocal中是否有用户，决定是否放行

**优势**:
- ✅ 职责分离（刷新 vs 校验）
- ✅ 灵活配置（不同路径不同策略）
- ✅ 自动续期（滑动窗口）

```java
@Override
public Result login(LoginFormDTO loginForm, HttpSession session) {
    // 1. 校验手机号
    String phone = loginForm.getPhone();
    if (RegexUtils.isPhoneInvalid(phone)) {
        return Result.fail("手机号格式错误！");
    }
    
    // 2. 从Redis获取验证码并校验
    String cacheCode = stringRedisTemplate.opsForValue().get(LOGIN_CODE_KEY + phone);
    String code = loginForm.getCode();
    if (cacheCode == null || !cacheCode.equals(code)) {
        return Result.fail("验证码错误");
    }
    
    // 3. 根据手机号查询用户
    User user = query().eq("phone", phone).one();
    
    // 4. 判断用户是否存在
    if (user == null) {
        // 不存在，创建新用户并保存
        user = createUserWithPhone(phone);
    }
    
    // 5. 保存用户信息到Redis
    // 5.1 随机生成token，作为登录令牌
    String token = UUID.randomUUID().toString(true);
    
    // 5.2 将User对象转为HashMap存储
    UserDTO userDTO = BeanUtil.copyProperties(user, UserDTO.class);
    Map<String, Object> userMap = BeanUtil.beanToMap(userDTO, new HashMap<>(),
        CopyOptions.create()
            .setIgnoreNullValue(true)
            .setFieldValueEditor((fieldName, fieldValue) -> fieldValue.toString()));
    
    // 5.3 存储
    String tokenKey = LOGIN_USER_KEY + token;
    stringRedisTemplate.opsForHash().putAll(tokenKey, userMap);
    
    // 5.4 设置token有效期
    stringRedisTemplate.expire(tokenKey, LOGIN_USER_TTL, TimeUnit.MINUTES);
    
    // 6. 返回token
    return Result.ok(token);
}

private User createUserWithPhone(String phone) {
    User user = new User();
    user.setPhone(phone);
    user.setNickName(USER_NICK_NAME_PREFIX + RandomUtil.randomString(10));
    save(user);
    return user;
}
```
